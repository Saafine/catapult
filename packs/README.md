# Asset packs

Everything the player sees lives in one pack folder. Switch the whole look of
the game (map, characters, pickups, strings) by pointing `packs/active.json`
at a different folder, or by setting `HAMSTERS_PACK=<name>` for a native run.

```
packs/
  active.json            which pack the game loads   {"pack": "calgary_xmas"}
  calgary_xmas/          first map: Christmas over Calgary, Alberta
    pack.json            strings (title, milestones, town signposts, labels)
    svg/                 vector sources, generated by tools/gen_svg.py
    sprites/             rendered PNGs the game loads at startup
    sounds/              optional: <name>.ogg or .wav replaces a synthesized sound
```

## Making a new pack

1. `PACK=summer_fair tools/gen_all.sh` writes `packs/summer_fair/svg/` and
   renders `sprites/` (edit the generators, or drop hand-made SVGs with the
   same names into `svg/` and run only `node tools/render_sprites.js`).
2. (nothing else to render)
3. Copy `pack.json` and change the strings.
4. Set `packs/active.json` to `{"pack": "summer_fair"}` and run `./build-web.sh`.

## Sprite roles

File names are roles, not subjects. A pack can draw them as anything as long
as the names and rough proportions match:

| file | role in the game |
| --- | --- |
| `dog_<pilot>_head_<face>` / `dog_<pilot>_body_<pose>` | the three pilots; faces idle/scream/panic/squint/dizzy/grit/whee, poses seated/dive/spread/flap_a/flap_b/tumble/land |
| `dog_<pilot>` | pilot portrait for the picker and results |
| `santa` | host on the launch tower |
| `elf_a`, `elf_b` | crew at the tower base, spectators along the run |
| `sled` | launch vehicle; `tower` launch tower (ramp is drawn by code) |
| `present_red/green/blue` | score pickups; `trampoline` ground bouncer; `reindeer` tow; `wings` glide; `firework` speed burst; `sleigh` big boost; `ufo` space boost; `updraft` wind column that throws the pilot up (a Chinook in Calgary); `coldwind` Arctic gust that freezes the pilot; `icecube` the frozen overlay; `stormcloud` hazard |
| `mountains_far/near`, `hills_far/near`, `treeline`, `meadow`, `ground` | parallax layers, back to front |
| `xmas_tree`, `pine_snow`, `snowman`, `lamppost`, `candycane`, `fence`, `signpost`, `gift_pile`, `tuft` | props |
| `moon`, `cloud_a/b/c`, `snowflake`, `star` | sky |
| `puff`, `sparkle`, `feather`, `ring`, `confetti`, `vignette` | effects |

## Sounds

Every sound is synthesized at startup, so a pack needs no audio files. To
replace one, drop `sounds/<name>.ogg` (or `.wav`) into the pack; names:
flap, bounce, present, milestone, land, launch, crash, zap, firework, pop,
freeze, jump, trampoline, reindeer, updraft, sleigh, ufo, wings, gust, and the
three looped wind layers wind, wind_mid, wind_high.

Background music is never synthesized: put public-domain tracks in
`sounds/music_1.ogg`, `music_2.ogg`, ... and they play as a looping playlist
from the first push; M toggles it. Track lengths are read from the Ogg pages,
so no extra metadata is needed. List attributions in `pack.json` under
`"credits"` (an array of strings).
